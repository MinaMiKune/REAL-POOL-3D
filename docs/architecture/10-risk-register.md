## 4. 仍未解决的关键架构问题

1. **SQLite ABI 与打包**：v4.9 针对 4.7.1 构建，能否在 4.7.2 desktop 和 API 37 Android arm64 完整工作未知。
2. **Android 构建组合**：Godot 4.7.2 生成的 Gradle/AGP 与 compileSdk 37、Build-Tools 37.x 的实际兼容组合未知。
3. **渲染器默认值**：没有设备帧时间、视觉和稳定性数据，不能选 Mobile 或 Compatibility 之一宣称完成。
4. **物理真实感与收敛**：公式探针不覆盖三维旋转耦合、多球接触、jaw、参数标定或跨平台浮点差异。
5. **LAN 权限与广播可达性**：Godot 请求链、AP 隔离、设备广播限制、后台网络行为均需实测。
6. **数字规则验收**：透明随机首局开球权、同时首碰有利合法目标、现实裁判事项排除需维护者认可。
7. **项目许可证和设备矩阵**：项目 LICENSE 未决定；可用 API 37 真机、低端设备和大屏设备尚未提供。

## 5. 阶段门禁建议

阶段 1 文档可审查，不代表上述风险关闭。阶段 2 必须优先解除 R-01/R-02，并完成 SQLite、Android、网络和渲染器的最小真实 PoC；若任何 Blocker/High 无证据，不得进入依赖该选型的正式功能。重大替代方案需回到 ADR 并等待维护者批准。
