# 阶段 9：Android 17 / API 37 适配与优化

前置条件：主要功能完成，已有可运行 Android 构建。

## 工具链与平台
核验 Godot 导出模板、Android SDK/Build Tools、JDK、Gradle、NDK（若需要）及目标 API 37 的实际兼容性。记录准确版本和安装路径，不得假定最新版必然兼容。

## 平台行为
检查安装、首次启动、权限拒绝/撤销、局域网权限、网络切换、后台/前台、屏幕旋转、音频焦点、存储策略、进程被系统回收和数据持久化。仅请求必要权限并解释用途。

## 性能
测量启动时间、稳定帧率、帧时间分布、内存、发热和耗电；建立低/中/高画质档，按设备能力选择并允许手动调整。优化物理更新、渲染批次、阴影、粒子、纹理和资源加载。

## 验收
至少在目标 Android 17 设备验证安装、启动、核心对局、暂停恢复、方向适配、数据和 LAN（如已实现）。报告设备型号、系统版本、分辨率、画质、时长和数据。模拟器结果单独标注。等待批准阶段 10。
