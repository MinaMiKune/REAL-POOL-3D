# 阶段 5：触控、镜头与 UI

前置条件：规则与 AI 阶段通过验收。

## 任务
- 设计瞄准、力度、击球确认、杆法调节、暂停和菜单的完整触控流程。
- 支持触屏拖动、点按、长按等交互；避免 UI 控件与桌面手势冲突。
- 设计球桌观察、瞄准和击球镜头；处理镜头限制、插值与切换。
- 横屏和竖屏分别布局，不只是简单缩放；适配刘海、圆角、安全区、不同长宽比和 DPI。
- 提供可访问的按钮尺寸、清晰反馈、操作取消/撤销和新手引导。
- 处理方向切换、窗口尺寸变化、触控中断和应用暂停恢复。
- UI 展示必须订阅游戏状态，不得自行复制或修改规则状态。

## 验收
模拟器与真实 Android 设备验证两种方向；记录分辨率、DPI、触控流程和缺陷。所有关键操作无需物理键盘/鼠标。等待批准阶段 6。
